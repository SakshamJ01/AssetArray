# ASSETARRAY 4.0 — DESIGN PRINCIPLES & INSTITUTIONAL UX
**Institutional Advisor Platform Product Blueprint**

## 1. The Visual Aesthetic: Private Bank Meets Bloomberg Terminal

AssetArray 4.0's visual language balances **Swiss Banking Elegance** with the **Information Density of an Institutional Trading Terminal**.

```
+-------------------------------------------------------------------------------+
| WHAT WE EMBRACE                    | WHAT WE STRICTLY AVOID                   |
+------------------------------------+------------------------------------------+
| Crisp, high-contrast typography    | AI-generated generic neon gradients      |
| Compact 36px table row heights     | Giant fluffy cards with 48px padding     |
| Purposeful semantic status badges  | Unreadable frosted glassmorphism spam    |
| Micro-interactions & inline hints  | Gratuitous 3D bouncing chart animations  |
| Progressive disclosure via drawers | 15 nested pop-up modal dialogs           |
| Muted institutional dark & light   | Low-contrast unreadable pastel text      |
+------------------------------------+------------------------------------------+
```

## 2. The 10 Core UX Principles for Wealth Advisers

1. **Context Before Action**: Never display a "Buy / Sell" or "Rebalance" button without first showing the underlying mandate, current drift percentage, and tax impact.
2. **Evidence Before Recommendation**: Every AI summary or analytical recommendation must link directly to clickable source data.
3. **One Primary Action Per Screen**: Avoid cognitive paralysis; each screen clearly highlights the single most important next step for the advisor.
4. **Dense Information, Not Dense Decoration**: Maximizing visible data points per square inch without visual clutter.
5. **Progressive Disclosure**: High-level summary visible above the fold; deep lot-level math and attribution available on click via right-hand slide-over drawers.
6. **Empty States are First-Class Training**: An empty client list or unconfigured model portfolio must guide the advisor with clear, 1-click import actions rather than a blank dead end.
7. **Mobile is Intentional, Not Compressed Desktop**: Mobile is optimized for lookup, meeting briefs, alerts, and quick approvals—not 80-column Excel editing.
8. **Every Number Has Provenance**: Hovering over any return (XIRR/TWR) or valuation reveals the exact as-of date, currency, and data source.
9. **Human Approval for Consequential Actions**: Consequential portfolio rebalances, tax-loss harvesting orders, and client communications require explicit human confirmation.
10. **Never Hide Financial Uncertainty**: If data is delayed, estimated, or unverified, state it plainly in the UI.
